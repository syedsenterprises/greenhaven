# GreenHaven — Home & Garden

Live demo site: a home & garden magazine + services business.

**What actually works (in your browser, no server needed):**
- Service "Book" buttons that pre-fill the consultation form
- Consultation booking with a reference number
- Newsletter signup saved locally

**Honest limits:** static front-end. Bookings and subscriptions are saved in
the visitor's browser only. Connect a form backend or email service to
receive them for real.
